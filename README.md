# Blood-Link 🩸

An AI-driven, geo-spatial, and predictive blood management system specifically engineered for Thalassemia care in South Punjab, Pakistan.

## 📌 Project Overview
Blood-Link is a Progressive Web Application (PWA) designed to eliminate the logistical and informational barriers between blood donors and Thalassemia patients. It replaces outdated paper-based registries and informal social media coordination with a real-time, intelligent platform.

## 🚀 Key Features
- **Predictive Demand Engine:** Utilizes LSTM neural networks to forecast blood shortage periods.
- **Dynamic Donor Ranking (DDR):** MCDM algorithm ranking donors by distance, real-time traffic, eligibility, and reliability.
- **Automated Thalassemia Lifecycle Management:** Triggers donation chain reminders 72 hours before scheduled transfusions.
- **Geo-Spatial Mapping:** Real-time GPS tracking of available donors via Leaflet.js.
- **Gamification:** Digital badges and leaderboards to incentivize voluntary donations.

## 🛠️ Technology Stack
- **Frontend:** Next.js 14, Tailwind CSS, Leaflet.js (PWA)
- **Backend / Database:** Firebase (Cloud Functions, Firestore, FCM, Hosting)
- **Machine Learning:** Python, TensorFlow / Keras, FastAPI
- **External APIs:** Google Distance Matrix API, Twilio SMS Gateway
